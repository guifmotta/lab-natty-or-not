# IA Generativa: Como a Inteligência Artificial está transformando nosso dia a dia e o que esperar do futuro 💻

## 📒 Descrição
Este e-book de 18 páginas fala sobre IA generativa, seus impactos no cotidiano, oportunidades, desafios e o futuro da relação entre humanos e tecnologia.

## 🤖 Tecnologias Utilizadas
- IA Generativa **[ChatGPT](https://chatgpt.com/)** para roteirização;
- IA Generativa **[Bing AI](https://www.bing.com/images/create/ai-image-generator)** para criar a arte visual do e-book;
- Ferramenta **Google Docs** para edição.

## 🧐 Processo de Criação
Utilizei o "ChatGPT" para revisar e complementar minhas pesquisas sobre IAs Generativas, estruturar o conteúdo da melhor forma. Utilizei o "Bing AI" para criar a imagem de capa do e-book e para concluir, a montagem final utilizei o "Google Docs" para estruturar, criar sumário e exportar o PDF.

## 🚀 Resultados
O e-book apresenta os impactos das IA Generativas em diversas áreas e nos traz diversas reflexões para o futuro.
